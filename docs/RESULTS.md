## Technique definitions

| Technique | Definition |
|---|---|
| CE (baseline) | Plain BCE (change) + CE (semantic), no balancing |
| Weighted CE | Inverse-sqrt-frequency class weights + BCE pos_weight |
| Median-freq | Median-frequency balancing (Eigen & Fergus) + BCE pos_weight |
| Class-balanced | Effective-number class-balanced loss (Cui et al., 2019) + BCE pos_weight |
| Focal | Focal loss, gamma=2 (alpha=0.75 on the change branch) |
| CE + Dice | CE/BCE plus soft Dice on both branches |
| OHEM | Online hard-example mining: mean of the hardest 25% of pixels |
| CE + rare sampling | Plain CE with rare-class image oversampling |
| WCE + Dice | Weighted CE + Dice (both branches) |
| WCE + Dice + rare sampling | Weighted CE + Dice with rare-class oversampling |
